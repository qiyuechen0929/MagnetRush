磁能狂飙：金币猎手
一个基于Web技术（HTML5 Canvas + JavaScript）开发的赛车躲避类游戏，具有华丽的视觉特效、语音助手、技能系统和车库改装系统。
🎮 游戏简介
《磁能狂飙：金币猎手》是一款单文件HTML5赛车游戏，玩家需要在道路上行驶，躲避障碍物，收集金币得分。游戏支持60fps流畅运行，具有三档难度选择、本地最高分保存、语音助手、技能系统和车库改装等丰富功能。
✨ 核心特色
🚗 游戏玩法
基础操作：使用WASD键控制车辆移动
oA/D：左右移动
oW/S：临时加速/减速（3秒持续时间）
计分系统：金币+10分，每存活5秒+5分
碰撞机制：碰撞障碍物直接游戏结束
🎯 技能系统
三技能共享充能：通过收集400分充能，三个技能同时可用
o1键 - 磁吸技能：吸引附近金币自动收集
o2键 - 雷电技能：清除附近障碍物
o3键 - 冰冻技能：冻结障碍物减速
充能机制：分数共享，充能完成后三技能都可使用
🏆 排行榜系统
每周排行榜：每周一自动重置
三难度独立排行：简单、中等、困难各有独立排行榜
本地存储：使用localStorage保存最高分和排名记录
🛒 车库系统
黄金货币：通过游戏表现获得黄金
装备购买：购买各种装备提升车辆性能
两页装备：
o第1页：基础装备（发动机升级、涡轮增压器、稳定器系统等）
o第2页：特殊装备（技能冷却优化、双倍分数推进器、额外生命模块等）
装备效果：只在游戏期间生效
🎭 语音助手系统
三种性格助手：
o可莉：天真可爱的御姐风格
o炼狱：威严冷静的大叔风格
o芮娜：专业高效的竞技风格
语音反馈：游戏事件实时语音播报
语音控制：支持开关和音量调节
⚙️ 设置选项
音效控制：游戏音效开关
音乐控制：背景音乐开关和音量
语音控制：语音助手开关和音量
难度选择：简单、中等、困难三档
📁 文件结构
text
car_game.html - 主游戏文件（包含HTML、CSS、JavaScript）
游戏采用单文件设计，所有代码、样式和资源都包含在一个HTML文件中，方便部署和分享。
🎨 视觉效果
60fps流畅动画：使用requestAnimationFrame实现
粒子特效：金币收集、技能释放、碰撞等都有华丽特效
动态HUD：实时显示分数、时间、技能状态等信息
暗色主题：采用深蓝色调，营造科技感氛围
技能图标：右侧显示三个技能图标，动态展示充能状态
💾 数据存储
使用localStorage存储以下数据：
最高分：各难度最高分
黄金数量：玩家拥有的黄金
装备状态：已购买的装备
排行榜数据：每周排行榜
周重置记录：用于每周黄金重置
🔧 技术特性
纯前端技术：HTML5 + CSS3 + JavaScript
Canvas渲染：800x600游戏画布
响应式设计：适应不同屏幕尺寸
Web Audio API：生成游戏音效和背景音乐
Web Speech API：实现语音合成功能
60fps优化：高效的渲染和更新逻辑
🚀 快速开始
1.直接使用浏览器打开car_game.html文件
2.游戏会自动加载，进入主菜单
3.选择难度和语音助手
4.点击“开始游戏”按钮开始游戏
5.使用WASD键控制车辆
🎮 游戏技巧
基础技巧
预判障碍：提前观察障碍物位置
控制速度：合理使用W/S键加速减速
收集金币：优先收集金币提高分数
技能使用
磁吸技能：在金币密集区域使用
雷电技能：在障碍物多时使用清理道路
冰冻技能：在复杂路况时使用争取时间
装备策略
优先升级发动机：提高基础移动速度
购买护盾：增加生存机会
根据玩法选择装备：喜欢收集金币选磁力收集器，喜欢挑战高难度选稳定器系统
📊 难度说明
简单：障碍少、速度慢、金币多
中等：平衡的游戏体验
困难：障碍多且更快，新增移动障碍物，BOSS出现时间更早
🔄 周重置系统
每周一0点：黄金数量重置为100
排行榜重置：每周重新开始排行榜
装备保留：已购买的装备不会重置
🎵 音效系统
背景音乐：轻快活泼的游戏音乐
游戏音效：金币收集、技能释放、碰撞等音效
语音合成：三种不同风格的语音助手
📱 兼容性
现代浏览器：Chrome、Firefox、Edge、Safari
移动设备：支持触控操作（需要外接键盘或虚拟键盘）
性能要求：需要支持Web Audio API和Web Speech API的浏览器
🐛 故障排除
常见问题
1.游戏卡顿
o关闭其他占用资源的程序
o降低浏览器硬件加速设置
o尝试使用Chrome或Firefox浏览器
2.没有声音
o检查浏览器是否允许自动播放音频
o检查游戏内的音效设置
o确保浏览器支持Web Audio API
3.语音助手不工作
o检查浏览器是否支持Web Speech API
o确保已开启语音功能
o检查网络连接（某些浏览器需要在线才能使用语音合成）
4.游戏无法保存进度
o检查浏览器是否允许localStorage
o尝试使用隐私模式外的正常模式
o清除浏览器缓存后重试
