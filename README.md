磁能狂飙金币猎手
基于 HTML5 Canvas + JavaScript 开发的单文件赛车躲避类网页游戏
拥有华丽视觉特效、多风格语音助手、三技能战斗系统、车库装备仓储、周榜排行与本地数据存储，支持 60fps 流畅运行，是一款功能完整、体验丰富的前端休闲竞速小游戏。
🎮 游戏简介
《磁能狂飙：金币猎手》为单文件 HTML5 赛车躲避游戏，无需复杂部署，浏览器直接打开即可游玩。玩家操控车辆在赛道行驶，躲避随机障碍物、收集金币累计积分。游戏内置三档难度、本地最高分记录、周度排行榜、智能语音助手、专属技能与车库装备系统，玩法丰富、交互流畅，画面具备科技感动态视觉效果。
✨ 核心特色
🚗 基础游戏玩法
操作方式：WASD 全键盘操控
A / D：车辆左右移动
W / S：临时加速 / 紧急救援，持续 3 秒
计分规则：收集单个金币 +10 分，每在线 5 秒额外 +5 分
游戏机制：触碰障碍物直接结束本局游戏
流畅体验：全程 60fps 高帧稳定运行，动态画面无卡顿
🎯 共享充能技能系统
三大技能共用一套充能机制，累计收集 400 积分即可解锁全部技能，同时可用。
【1 键】磁吸技能：自动吸附屏幕附近所有金币，快速刷分
【2 键】雷电技能：清除赛道周边全部障碍物，开辟安全道路
【3 键】冰冻技能：临时锁定存储赛道障碍物，规避突发碰撞风险
🏆 周度排行榜系统
独立榜单：简单、中等、困难三档难度，各自拥有独立最高分排行榜
周度重置：每周一零点自动清空榜单，开启全新赛季排名
本地持久化：基于 localStorage 存储最高分、排名记录，数据不丢失
🛒 车库装备仓储系统
游戏对局获取黄金货币，可在车库购买装备、永久提升载具对局性能，装备仅对局内生效。
第一页・基础装备：引擎升级、缓冲购买器、稳定器系统等，提升车辆基础行驶属性
第二页・特殊装备：技能冷却优化、双倍积分推进器、额外生命模块等高阶增益效果
🎭 多风格语音助手系统
内置三种性格迥异的智能语音助手，全程实时播报游戏事件，支持自定义开关与音量调节。
可莉：天真可爱的元气风格
炼狱：沉稳威严的大叔风格
芮娜：冷静专业的竞技风格
⚙️ 自定义设置选项
音效开关：独立控制游戏碰撞、金币、技能音效
音乐设置：背景音乐开关、音量大小调节
语音设置：语音助手启停、音量自定义
难度选择：简单 / 中等 / 困难三档自由切换
📁 项目文件结构
本项目采用单文件极简设计，所有 HTML 结构、CSS 样式、JavaScript 逻辑全部集成于一个文件，无需依赖、开箱即用、方便分享与部署。
car_game.html：项目唯一主程序文件
画面与交互特性
基于 requestAnimationFrame 实现 60fps 极致流畅动画
丰富粒子特效：金币收集、技能释放、碰撞爆炸等动态视觉效果
动态 HUD 界面：实时展示分数、对局时长、技能充能状态
深色科技主题：深蓝色调 UI，视觉舒适、氛围感拉满
动态技能图标：实时刷新充能进度、可用状态提示
💾 本地数据存储
依托浏览器 localStorage 实现数据持久化，关闭页面不丢失数据：
三档难度历史最高分记录
玩家持有黄金货币数量
已购买装备状态数据
周度排行榜数据
每周重置时间记录
🔧 技术栈
纯前端原生技术：HTML5 + CSS3 + JavaScript
画布渲染：800×600 标准游戏画布尺寸
响应式适配：兼容多类屏幕尺寸
Web Audio API：实现游戏音效、背景音乐生成与播放
Web Speech API：实现智能语音合成、实时语音播报
60fps 高性能渲染：优化更新与渲染逻辑，杜绝画面卡顿
🚀 快速开始
使用任意现代浏览器打开 car_game.html 文件
程序自动加载，跳转至游戏主菜单
自主选择游戏难度、语音助手风格
点击开始游戏按钮进入对局
使用 WASD 按键操控载具进行游戏
🎮 游戏技巧
雷电技能：障碍物密集时使用，快速清理赛道障碍，规避碰撞
冰冻技能：复杂混乱路况使用，锁定障碍物，争取通关时间
装备升级建议：优先升级移动速度、护盾类装备，提升生存能力
玩法适配搭配：刷分玩法选择磁力收集器装备，高难度挑战选择车辆稳定器装备
📊 难度说明
简单：障碍物数量少、车辆行驶速度慢、金币刷新数量多，适合新手入门
中等：障碍密度、行驶速度、金币刷新概率均衡，体验最平衡的游戏玩法
困难：障碍物多、移动速度快，新增动态移动障碍物，BOSS 障碍出现时间更早，挑战性极强
🔄 周重置系统
每周一 0 点：玩家黄金数量自动重置为 100
每周一 0 点：全难度排行榜数据清空重置，重新统计排名
永久保留：玩家已购买的所有装备、解锁内容不会被重置
🎵 音效系统
背景音乐：轻快科技风游戏背景音乐，沉浸感十足
对局音效：金币收集、技能释放、车辆碰撞等专属音效
语音合成：多风格真人化语音助手实时事件播报
📱 兼容性
支持浏览器：Chrome、Firefox、Edge、Safari 最新现代浏览器
操作设备：支持键盘外设操作
运行要求：浏览器需支持 Web Audio API、Web Speech API
🐛 故障排除
常见问题解决
游戏卡顿
关闭电脑后台占用资源的程序
调整浏览器硬件加速设置
优先使用 Chrome、Firefox 浏览器运行
无游戏声音
开启浏览器音频自动播放权限
检查游戏内音效、音乐开关设置
确认浏览器支持 Web Audio API
语音助手无播报
确认浏览器支持 Web Speech API
检查游戏内语音功能是否开启
保证网络正常（部分浏览器语音合成需联网）
无法保存游戏数据
开启浏览器本地存储权限
退出隐私 / 无痕模式运行游戏
清除浏览器缓存后重新打开
